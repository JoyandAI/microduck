未跟随

systemd 把各 *d 的 stdout / stderr 收进 journal。选一个进程，或看全部。

进程

robotd、padd、mediad、btd、configd、updaterd、tofd 走 journalctl。webd 若从终端启动，本页直接显示它自己的 tracing（stderr），不必经过 journal。

过滤

stdout 是 journal 里 PRIORITY 5–7（println 这类）；stderr 是 0–4。Rust tracing 默认写 stderr，所以 robotd 的 WARN / ERROR 在 stderr。robotd 总线校验那行 read crc 在 stdout。
