动作

起立会给所有关节上力矩，并在大约两秒内走到站姿，先放在支架上或扶好。开始行走之后，下面的摇杆才让它走。卸力会关掉力矩，没人扶的话会倒下。

行走

前进 0.00 · 侧移 0.00

转向 0.00

松开摇杆回到零。键盘 WS 前进，AD 侧移，QE 转向，空格速度归零。满杆大约 0.3 m/s、1.5 rad/s。页面关掉或切到后台后，速度指令会停。

技能

这些和手柄上的动作是同一条指令。需要先「开始行走」。按住「翻滚」会连着翻。

头和嘴

头的四个数是弧度，大约 ±1。嘴 0 是闭上，1 是张开。
