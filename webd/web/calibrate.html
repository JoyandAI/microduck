这一页直接写舵机总线。先执行 sudo systemctl stop robotd，用完再启动。设 0 位会把当前位置写成编码器中位 2048，并保存在舵机里。先把关节摆到机械零位再按。

连接串口后开始。开始标定会把增益设为 KP=32、KD=40，15 路先走到 2048。标定时需要硬的关节，才能定准位置。

步骤

拖动滑条只改这一路，范围是编码器 0–4095。摆到机械零位后按「设 0 位」。绿色表示这次打开页面后已经设过。退出或离开页面会卸力矩，并把增益恢复成 KP 32、KD 40。已经写入舵机的 0 位不会被清掉。「运行到默认位置」走到 robotd.toml 里的 policy.home，没写过就用程序里的站姿。0 位设好之后这个姿势才准。「保存为默认站姿」把当前十五路角度按度写进同一份配置。策略看到的关节角是相对这组站姿的，所以保存之后要重新启动 robotd，控制环才会用新的零点。这一页马上就用新的。
